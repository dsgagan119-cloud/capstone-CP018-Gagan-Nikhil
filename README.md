# CP-018 PriceRadar

## Project
PriceRadar is a multi-seller price comparison and alert engine.

## Features
- Store products from 3 or more sellers
- Compare price + delivery charge
- Show cheapest total price
- Track price history
- Show lowest price ever
- Set target price alerts
- Search products
- Sort products by name, price and delivery days

## Technology
- Java
- IntelliJ IDEA
- GitHub

## How to Run
Open the project in IntelliJ IDEA and run `Main.java`.
