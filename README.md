## **Project Description**

PriceRadar is a product price comparison system designed to help users compare product prices from different sellers. It organizes product and seller offer information to help users identify suitable purchasing options.

---

## **How to Run the Program**

### **Prerequisites:**

- Java JDK installed.
- IntelliJ IDEA or another Java IDE.
- Git installed (optional).

### **Steps:**

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Navigate to the "PriceRadar" folder.
4. Open `src/priceradar/Main.java`.
5. Configure the JDK if required.
6. Run the `Main.java` file.
